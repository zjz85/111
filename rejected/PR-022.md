### 问题 1 详情（reject）

`production/src/agent-orchestrator/agents/mcp-reviewer-tools.ts` 第 12 行：

```
const SERVER_ENTRY_SRC = path.resolve(
  import.meta.dirname, "..", "..", "mcp-server", "index.ts",
);
```

该文件位于 `production/src/agent-orchestrator/agents/`，上溯 2 层得到 `production/src/`，再拼接 `mcp-server/index.ts` 得到 `production/src/mcp-server/index.ts`——这是迁移前的旧路径，迁移后该目录已不存在。

**正确写法**：应上溯 4 层到仓库根再拼接 `mcp-server/index.ts`，即 `'..','..','..','..','mcp-server','index.ts'`。

**危害**：评审 Agent 调用 `query_rule` 时 MCP client 无法启动 server，导致规范检索失败，评审流程降级或中断。
