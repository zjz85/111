# 双区切换决策

## 文件说明

- **定位：** 代码从探索区（exploration）迁移到生产区（production）的准入标准与决策流程
- **核心理念：** 探索区自由试错，生产区严格准入

---

## 一、区划定义

| 区域 | 目录 | 定位 |
|---|---|---|
| 探索区 | `exploration/` | 原型实验，先跑通再说 |
| 生产区 | `production/` | 正式代码，经得起评审和线上流量 |

---

## 二、切换准入标准（4 条，全部满足）

1. **接口契约完整** — 按 `接口契约.md` 定义好入参、返回值、异常码
2. **通过复杂度审查** — 满足 `复杂性预算说明.md` 的 4 条底线
3. **测试覆盖达标** — 核心路径 + 边界 + 失败场景有测试
4. **依赖已收敛** — 不依赖探索区代码和临时三方包

---

## 三、切换流程

```
自查（对 4 条标准） → 填申请单 → 评审 → 通过则迁移 / 不通过则打回
```

---

## 四、切换申请单

| 项 | 内容 |
|---|---|
| 申请日期 | YYYY-MM-DD |
| 探索区路径 | exploration/xxx |
| 目标生产区路径 | production/xxx |
| 接口契约 | □ 已完成 □ 未完成 |
| 复杂度自查 | □ 通过 □ 不通过 |
| 测试覆盖 | □ 核心路径 □ 边界 □ 失败 |
| 从探索区独立 | □ 是 □ 否（依赖了探索区其他代码） |

---

## 五、打回常见原因

| 原因 | 对应标准 |
|---|---|
| 接口没定义清楚 | 第 1 条 |
| 职责混杂、重复逻辑多 | 第 2 条 |
| 传非法参数直接崩 | 第 3 条 |
| 引用了探索区临时代码 | 第 4 条 |
